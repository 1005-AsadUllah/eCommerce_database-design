# 🛒 eCommerce Database Design

This repository contains a visual database design for an **eCommerce system**, created using **draw.io**. It models the essential entities and relationships needed to manage products, customers, orders, and other components of an online store.

## 📌 Project Overview

The purpose of this project is to design a **relational database schema** for an eCommerce application. This schema serves as a foundation for developers who want to build a functional eCommerce system with proper data structure.

## 📂 Contents

- `ecommerce.drawio` – The visual ER diagram designed using draw.io

## 🧩 Key Entities

The design includes (but is not limited to) the following main entities:

- **Customer** – Stores customer info
- **Product** – Details about each product
- **Category** – Classification of products
- **Order** – Records of customer purchases
- **Order_Item** – Items within each order
- **Cart** – Temporary list of products selected by the customer
- **Payment** – Tracks payment details
- **Shipping_Address** – Delivery information for orders

## 🛠 Tools Used
